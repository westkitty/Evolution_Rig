# Causal Observatory / visual and interaction contract

## Design thesis

Make an evolutionary idea generator feel like an instrument for observing consequences. The strongest revelation is not an invented cosmos: it is the visible emergence of a family of competing proposals, including archived and weakened alternatives that remain attributable to the original seed.

## Verified truth represented

- One plotted point = one saved idea from the selected board; radius increases subtly with its structural jury total.
- One edge = one actual `parents[]` reference. Two edges denote crossbreeding rather than a fictional relationship.
- Concentric rings = recorded `generation` values, not literal time or physical distances.
- Gold rim = current computed gold shortlist; gray hollow point = archived. User-selected idea and its actual ancestry/descendant paths receive warm highlight.
- Generation slider limits only the visualization. It never deletes, creates, changes or retimes ideas.
- No faux telemetry, no invented canon, no particle ambience, no artificial plot events, no fake view counts or human-success claims.

## Visual DNA

Warm archive brass marks decision/selection and gold. Mineral teal marks active records. Pale green-gray marks historical/archived traces. Deep obsidian-blue supports contrast and makes the network the primary image. Serif display headlines provide editorial gravity; monospace labels carry machine metadata. Thin coordinate lines and rings are literal navigational scaffolding, not decorative stars. Hover/focus effects give feedback; no continuous motion makes the field costly or distracting.

## Interaction map

Board -> seed -> lineage atlas -> select/trace -> side report -> original inspector/jury -> branch/crossbreed/export. The user can reverse the reveal with the slider, recover the whole field with Fit, and use the original HTML tree and jury table when the canvas is inaccessible or unsuitable. The semantic side report communicates ancestry, descendant counts, archive counts and heuristic score caveats in words, not just color. The selected record also projects a small, explicitly labeled chart of the highest-scoring ancestor at each ancestral generation; it is a heuristic trajectory, never a claimed real-world outcome.

## Performance and safeguards

The Canvas renderer runs on demand after board/selection/depth/zoom/resize changes. Pixel ratio is capped at 2. No timers, audio, shaders, external network, images, or font downloads are used. Existing jury snapshot caching is preserved on selection-only navigation. Style overrides keep the original input, dialog and graphical tree contracts. Reduced-motion settings require no alternative animation since there is no continuously animated background.

## Boundaries / honest omissions

This project is a local-first idea workbench, not an existing playable video game or a canonical fictional universe. No characters, scenes, levels, VFX assets or lore were invented. External provider CORS and real-origin persistence were not proven. Browser storage, advanced screen-reader behavior and low-power soak remain environment-specific acceptance checks.
