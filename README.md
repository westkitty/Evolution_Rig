# Evolution Rig — Causal Observatory

Local-first evolutionary idea laboratory. Create idea boards, branch and crossbreed ideas, inspect jury scores, trace ancestry in the Causal Observatory, and export qualified candidates.

**Launch:** Open [Evolution Rig](https://westkitty.github.io/Evolution_Rig/) once GitHub Pages has been enabled and deployed, or download `index.html` and open it locally. The application is self-contained, with no runtime CDN dependencies.

**Important:** The browser stores work locally per origin. Back up with **Export workspace JSON**. The hosted Pages origin has separate browser storage from the standalone file. Do not put API keys into repository files.

The jury is a structural heuristic, not a verified assessment of real-world originality or impact. Model provider calls require explicit endpoint configuration and may be restricted by browser CORS.

Release: Causal Observatory v1.2.
