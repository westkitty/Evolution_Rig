OPERATOR CONTROLLED
Runs only while this page remains open. Browsers may throttle timers in background tabs; closing the page stops evolution. No persistent service or hidden agent is installed.

Effective interval: 300 seconds per step (bounded by both controls).

Selection favors strong active candidates while occasionally exploring alternatives. Pruning means archiving the lowest-scoring low-value leaves, not deleting their ancestry.

Trust boundaries

LOCAL

Seed creation, scoring, calibration, pruning, lineage, saving and exports work entirely in the browser.

MODEL ROUTES

Only user-triggered generations and connection tests contact the configured endpoint. Model payloads include the current board directive and selected parent fields.

CREDENTIALS

Keys live in sessionStorage by default or localStorage on explicit opt-in. They are not included in project ZIPs or workspace JSON. Browser storage is not a security vault; do not use high-privilege keys on shared computers.

CORS + BROWSER LIMITS

Some APIs block cross-origin browser requests. Ollama may need permitted origins; local HTTP endpoints should be bound to loopback. For strict offline guarantees, choose Offline. No secret-holding server proxy is bundled.

EXPORT

Gold project exports are standard ZIP folders. On browsers supporting directory write access, you can also choose an output folder without uploading data.
